# Dehiwala-dashboard
Urban analysis dashboard for Dehiwala Junction, Colombo — PL2306 Assignment 01, University of Moratuwa. Visualizes sDNA centrality, Space Matrix indices (FSI/GSI/OSR), Urban Maturation Index, land-use entropy, environmental comfort (UTCI/heat), population data, and live weather &amp; air quality via Open-Meteo API.
